# NeoReader

**NeoReader** 是全新的 **Flutter** 离线电子书阅读器（移动优先：Android / iOS）。
功能蓝本对齐开源 [Koodo Reader](https://github.com/koodo-reader/koodo-reader)
离线范围（AGPL-3.0）。界面：**Material Design 3 + 毛玻璃**。

- 纯离线 — **无**账号、同步、云盘、Pro、在线更新
- 本地书库 **无数量上限**
- 平台：Android **10+（API 29）**、iOS **12.0+**

详细说明与运行方式见 [README.md](./README.md)。完整功能清单与「一个不少」路线图见
[ROADMAP.md](./ROADMAP.md)。许可与致谢见 [ATTRIBUTION.md](./ATTRIBUTION.md)。

## v1 已实现

书库、导入 EPUB/PDF/TXT、阅读器主题与进度、书签/笔记/高亮、中英设置、
阅读时长统计（今日/累计）。其余 Koodo 格式与能力（mobi/azw3、fb2、漫画、
md/docx、TTS、词典、OCR、竖排、双栏、导出、PIN 等）已在模块中占位，见路线图。
